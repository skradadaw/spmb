# SPMB (Sistem Penerimaan Mahasiswa Baru)

Repositori untuk pengembangan sistem seleksi dan pendaftaran mahasiswa baru (SPMB).

## 🚀 Fitur Utama (Rencana Pengembangan)
- **Pendaftaran Akun & Verifikasi**: Registrasi calon mahasiswa/peserta didik baru.
- **Pengisian Formulir & Biodata**: Input data pribadi, riwayat pendidikan, dan pilihan program studi/jurusan.
- **Upload Dokumen**: Berkas persyaratan (ijazah, rapor, kartu identitas, pas foto).
- **Pembayaran & Verifikasi Tagihan**: Integrasi bukti bayar / payment gateway.
- **Pengumuman Kelulusan**: Cek hasil seleksi dan daftar ulang.
